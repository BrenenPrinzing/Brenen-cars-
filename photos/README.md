# Car photos

Put Brenen's own photos here, one folder per stock number:

    photos/C12345/01.jpg
    photos/C12345/02.jpg

Rules (spec R5):
- Only photos Brenen took or has the right to use. No images saved from the store's website.
- `.jpg` or `.webp`, longest side 1600px or less.
- Location data removed. The converter refuses to build if a photo still has GPS in its EXIF.
- Photos show in file-name order, so name them 01, 02, 03.
